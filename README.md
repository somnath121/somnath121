## What I'm building

### LocalAI

A native macOS coding environment for experimenting with **local agentic development**.

**Swift + MLX + Qwen**

* local inference
* project-aware context
* tool execution
* specialist agents
* controlled filesystem access

### Graphify

A project-intelligence layer that converts source code into structured knowledge for agents.

```text
Source Code
    ↓
   AST
    ↓
Graphify
    ↓
Project Knowledge
    ↓
Relevant Context
    ↓
Agent
```

The idea:

> **Don't give the model more context. Give it better context.**
