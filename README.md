## 👋 About

I'm a **Principal iOS Engineer** exploring the intersection of mature mobile engineering and **local AI systems**.

My current focus is building developer tooling where:

* AI runs locally on Apple silicon
* agents understand the structure of a real software project
* source code is converted into reusable project knowledge
* context is retrieved intelligently instead of repeatedly feeding entire codebases into an LLM
* filesystem and command access remain explicitly controlled

I’m particularly interested in:

**Swift · UIKit · SwiftUI · MLX · Local LLMs · RAG · Agentic AI · ASTs · Developer Tooling**

## 🕸️ Graphify

Instead of asking an LLM to rediscover a codebase for every question, Graphify builds structured knowledge from the project.

```text
 Source Project
      │
      ▼
     AST
      │
      ▼
 ┌─────────────┐
 │  Graphify   │
 └──────┬──────┘
        │
        ├── Types
        ├── Files
        ├── Dependencies
        ├── Relationships
        ├── APIs
        └── Architecture
              │
              ▼
        Project Knowledge
              │
              ▼
           Agents
```

The goal is simple:

> **Give the model the smallest useful context instead of the largest possible context.**
