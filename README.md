## 🕸️ Graphify

**Graphify** is the project-intelligence layer.

Instead of asking the LLM to repeatedly rediscover the structure of a codebase, Graphify derives structured knowledge from source code.

```text
                    Source Project
                          │
                          ▼
                         AST
                          │
                          ▼
                      Graphify
                          │
          ┌───────────────┼───────────────┐
          │               │               │
        Types           Files       Dependencies
          │               │               │
          └───────────────┼───────────────┘
                          │
             Relationships · APIs
                          │
                          ▼
                  Project Knowledge
                          │
                          ▼
                        Agents
```

> **Give the model the smallest useful context instead of the largest possible context.**

The aim is to reduce unnecessary context consumption while giving agents a stronger understanding of the project they're working with.
